# 屏幕贴图 / 准星（screen-overlay）

在屏幕上叠加一张贴图或一个准星。窗口无边框、背景完全透明并始终置顶，
支持贴靠屏幕四角与屏幕居中显示，亦可将鼠标事件透传给下层窗口。
覆盖方案参照 [desktop-pet-ai](https://github.com/toki-2004/desktop-pet-ai) 的实现。

## 功能

- 载入 PNG / JPG / BMP / WebP 格式的贴图，按原始宽高比显示
- 一键恢复原始大小（1:1，4×4 的图像占 4×4 个屏幕像素）
- 内置准星：红 / 绿 / 青 / 白四色，中心留空并带中心点
- 定位：左上 / 右上 / 左下 / 右下贴边（边距可调）与屏幕居中
- 窗口置顶、鼠标穿透、不透明度 100 / 85 / 70 / 55 / 40%
- 设置自动保存至 `overlay_config.json`，该文件与脚本或可执行文件位于同一目录

## 运行

方式一：免安装版本。从 [Releases](../../releases) 页面下载
`screen-overlay-v1.0.4-win64.zip`，解压后运行 `screen-overlay.exe`。
全部依赖与可执行文件位于同一目录，须整体保留；许可文件与配置文件亦位于
该目录，建议将整个目录放置于固定位置。

方式二：源码运行，需要 Python 3 与 PyQt5：

```
pip install PyQt5
python overlay.py              # 默认显示准星
python overlay.py 贴图.png      # 直接打开指定图像
```

## 操作

| 操作 | 效果 |
| --- | --- |
| 左键拖动 | 移动贴图，位置模式切换为自由位置 |
| 滚轮 | 放大 / 缩小 |
| 右键 | 打开菜单：载入图片、内置准星、贴边位置、边距、放大 / 缩小、原始大小（1:1）、准星颜色、不透明度、窗口置顶、鼠标穿透、显示 / 隐藏、退出 |
| 托盘图标单击 | 显示 / 隐藏窗口 |

- 贴边与居中均以「窗口当前所在屏幕」的完整屏幕范围计算（包含任务栏区域）：
  居中即屏幕正中，贴边即屏幕实际四角，任务栏不会造成偏移。窗口始终置顶，
  因此贴近屏幕下缘时，贴图或准星会覆盖在任务栏之上。多显示器环境下，
  请先将窗口拖至目标屏幕，再选择贴边位置。
- 启用「鼠标穿透」后，窗口不再接收鼠标事件，此时只能通过托盘图标的菜单操作。
- 作为游戏内准星使用时，游戏须设置为「无边框窗口」或「窗口化」模式；
  独占全屏会覆盖本程序的窗口。

## 已知限制

- 仅支持 Windows（鼠标穿透由 Windows 扩展窗口样式实现）
- GIF 仅显示首帧，不播放动画
