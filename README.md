# 屏幕贴图 / 准星（screen-overlay）

把图片贴到屏幕上，或者用内置准星：无边框 + 全透明 + 置顶的小窗口，
支持贴到屏幕四角与居中，可鼠标穿透。覆盖方案沿用
[desktop-pet-ai](https://github.com/toki-2004/desktop-pet-ai) 的透明置顶窗口做法。

## 功能

- 载入 PNG / JPG / BMP / WebP 贴图，按原图比例显示
- 一键恢复原始大小（1:1，4×4 的图就占 4×4 个屏幕像素）
- 内置准星：红 / 绿 / 青 / 白四色，中心留空 + 中心点
- 定位：左上 / 右上 / 左下 / 右下贴边（边距可调）、屏幕居中
- 窗口置顶、鼠标穿透、不透明度 100/85/70/55/40%
- 设置自动保存到 `overlay_config.json`（与脚本或 exe 同目录）

## 运行

方式一：免安装 exe。到 [Releases](../../releases) 下载
`screen-overlay-v1.0.1-win64.zip`，解压后双击 `screen-overlay.exe`。
依赖都在同目录，别只把 exe 单独拷走；配置写在 exe 同目录的
`overlay_config.json`，整个文件夹放固定位置即可。

方式二：源码运行，需要 Python 3 + PyQt5：

```
pip install PyQt5
python overlay.py              # 默认显示准星
python overlay.py 贴图.png      # 直接打开一张图片
```

## 操作

| 操作 | 效果 |
| --- | --- |
| 左键拖动 | 移动贴图（切换为自由位置） |
| 滚轮 | 放大 / 缩小 |
| 右键 | 菜单：载入图片、内置准星、贴边位置、边距、放大/缩小、原始大小(1:1)、准星颜色、不透明度、置顶、穿透、退出 |
| 托盘图标单击 | 显示 / 隐藏窗口 |

- 贴边与居中都按「窗口当前所在屏幕」的整块屏幕计算（含任务栏区域）：
  居中就是屏幕正中心，贴边就是屏幕真实的四角，不会被任务栏顶偏。
  窗口置顶，贴到下方时准星/贴图会盖在任务栏上面。多屏时先把窗口拖到目标屏，
  再选贴边位置。
- 开启「鼠标穿透」后窗口不再接收点击，只能从托盘图标菜单操作。
- 游戏内当准星用：游戏需设为「无边框窗口 / 窗口化」，独占全屏会盖住覆盖窗。

## 已知限制

- 仅 Windows（鼠标穿透由 Windows 扩展样式实现）
- GIF 只显示首帧，不做动画播放
